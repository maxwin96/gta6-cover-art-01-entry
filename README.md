Vice Sunset Cover Maker — turn your photo and caption into GTA 6-style cover art: multi-panel layouts, bold caption lettering, and a Vice City sunset/neon colour grade, exported as a PNG in 1080x1080, 1080x1350, or 1920x1080. Runs fully offline in a desktop browser; photos never leave your machine. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser, load a photo (or a sample), arrange the panels, write a caption, and export a PNG.
